TradingTransformer Privacy Policy

Effective date: 2026-07-03

Summary

TradingTransformer does not track you. There are no analytics, no cookies, no advertising identifiers, and no sale or sharing of data with third parties for their own purposes.

What the extension stores

Two values, in Chrome's own extension storage (chrome.storage.sync): the API server URL and the API key you enter in Settings. Backtest results are cached per browser tab in chrome.storage.session and discarded when the browser closes. Nothing else is stored on your device.

What is sent to the server

When you request a backtest or event detection, the extension sends the text of the article you are viewing (or its URL) and your API key to the API server you configured. If you use a self-hosted server, no data leaves your machine's network at all.

What the hosted server keeps

  • Request-level logs (timestamp, endpoint, response code) with a 7-day retention.
  • Backtest result files, deleted automatically after 7 days.
  • Article text is processed in memory per request. Where event detection needs an AI fallback, an excerpt (max 1,500 characters) is forwarded to Anthropic's API for extraction and is subject to Anthropic's privacy policy; it is not used for model training.

What is never collected

Browsing history, page content from pages you do not explicitly backtest, personal identifiers, financial account information.

Permissions

The extension requests activeTab/scripting (read the article you invoke it on), storage (save your settings), and host access used solely to contact the API server URL you configure. It never injects content into or reads pages except the one you explicitly backtest.

Contact

Questions or deletion requests: open an issue at the project repository.
